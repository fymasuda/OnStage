🚛 1. Logística

1.1 Conceito de Logística e Cadeia de Suprimentos

Logística é o conjunto de atividades que planeja, implementa e controla o fluxo eficiente e eficaz de mercadorias, serviços e informações desde o ponto de origem até o ponto de consumo.

Cadeia de Suprimentos (Supply Chain): rede mais ampla — fornecedores → fabricantes → distribuidores → varejistas → consumidores. A logística é o subsetor que cuida da movimentação e armazenagem.

Ballou (2007): Logística empresarial = atividades de movimentação e armazenagem que facilitam o fluxo de produtos desde a aquisição da matéria-prima até o consumo, mais os fluxos de informação.

1.2 Três Áreas da Logística

1.7 Indicadores de Estoque LACINHO

Giro de Estoques Giro = Valor Consumido no Período / Valor do Estoque Médio no Período
Cobertura (dias) Cobertura = Nº de Dias do Período / Giro
Exemplo: Saídas R$ 1.667.037,59 | Estoque médio R$ 96.099,53
Giro = 1.667.037,59 / 96.099,53 = 17,34 giros/ano
Cobertura = 180 dias / 17,34 = 10,38 dias de estoque

Interpretação: giro alto = capital girando rápido; cobertura baixa = pouco capital parado.

1.8 Cubagem e Peso Cubado LACINHO

Cubar uma carga = calcular volume para cobrança de frete. O frete é cobrado pelo maior entre peso real e peso cubado.

Peso Cubado = Volume (m³) × Fator de Cubagem
ModalFator (kg/m³)1 m³ =
Rodoviário300 kg/m³300 kg
Aéreo166,7 kg/m³166,7 kg
Marítimo1.000 kg/m³1.000 kg
Exemplo: Caixa 2m × 1m × 1m = 2m³
Rodoviário: 2 × 300 = 600 kg cubados
Aéreo: 2 × 166,7 = 333,4 kg cubados
Marítimo: 2 × 1000 = 2000 kg cubados
Se peso real > peso cubado → usa peso real.

1.14 Modal Rodoviário LACINHO

Características: carga fracionada, alta frequência, porta-a-porta, sem necessidade de carga/descarga intermediária.

CIOT: Código Identificador da Operação de Transporte — registro eletrônico obrigatório do frete rodoviário pago, integrado ao MDF-e.

Reboque vs Semirreboque: Reboque tem eixos próprios independentes (não transfere peso ao trator). Semirreboque apoia parte do peso no caminhão via 5ª roda — usado para cargas pesadas.

Frota Ecoeficiente: modernização, otimização de rotas, gestão de combustível, energias alternativas, manutenção preventiva, telemetria, rodas de liga leve.

1.15 Modal Ferroviário LACINHO

Cargas típicas: minério de ferro, soja/milho, produtos siderúrgicos, carvão, derivados de petróleo, fertilizantes, cimento.

Características: longas distâncias, baixa velocidade, precisa de outro modal para entrega, baixo custo, 66% menos CO₂.

Locomotivas: Manobra (formação de trens) e Percurso (tracionam o trem).

Vagões Hopper: abertura superior para descarga — grãos, minério, carvão.

1.19 Sistemas de Abastecimento

Sistema Convencional

Cada fornecedor entrega separadamente — rotas independentes, sem otimização, pode gerar custos maiores e prazos maiores.

Sistema Milk Run

Roteiro e horário predefinidos para coletas em múltiplos fornecedores. Objetivo: reduzir custos via economia de escala e racionalização de rotas.

Vantagens Milk Run: reduz custos de transporte (único veículo, múltiplas coletas), reduz estoques (entregas frequentes/pequenas), otimiza cadeia, reduz desperdícios de embalagem.

1.20 Cross Docking LACINHO

Produtos de vários fornecedores recebidos em CD e redistribuídos para destinos finais, com pouco/nenhum tempo de armazenagem.

Fornecedor 1 → Cross Dock → Cliente A

Tipos: Distribuição (consolida p/ destinos diferentes), Manufatura (p/ linha de produção), Transporte (reorganiza cargas).

E-commerce: loja recebe pedido → fornece fornecedor → fatura e remete direto ao cliente.

1.21 Logística Enxuta LACINHO

Filosofia Lean (Sistema Toyota de Produção) aplicada à logística: eliminar desperdícios, maximizar eficiência, garantir que cada atividade agregue valor.

4 Princípios:

  1. Valor para o Cliente: identificar o que é valor e entregar exatamente isso
  2. Fluxo Contínuo: processos sem interrupções, minimizar tempos de espera
  3. Produção Puxada: mover produtos conforme demanda real (não empurrar)
  4. Melhoria Contínua: PDCA — Planejar, Fazer, Verificar, Agir

1.22 Last Mile LACINHO

Última etapa da entrega — do centro de distribuição ao cliente final. É a fase mais cara e complexa da logística.

Desafios: tráfego urbano, variedade de endereços, primeira tentativa de entrega falha, custo proporcional alto.

1.23 Dropshipping LACINHO

Vender online sem estoque — loja virtual é intermediária. Fornecedor envia direto ao cliente.

1. Cliente compra → 2. Lojista pede ao fornecedor → 3. Fornecedor envia p/ cliente

Vantagens: baixo investimento, sem espaço físico, vende p/ todo Brasil.

Desvantagens: alta concorrência, controle de envios limitado, margem menor, taxação aduaneira (internacional).

Dropshipping vs Outsourcing: Dropshipping = fornecedor direto das mercadorias. Outsourcing = empresa distribuidora especializada.

1.24 Fulfillment LACINHO

Conjunto de processos do pedido à entrega: receber pedido → separar → embalar → expedir → entregar. Facilita expansão do negócio (vendedor não preocupa com distribuição).

1.25 Embalagens LACINHO

Funções: proteger, preservar, facilitar manuseio/transporte/comercialização, informar (natureza, qualidade, origem), auxiliar venda (aparência, identificação).

Normalização: ABNT, INMETRO (Brasil); ISO, IEC (internacional).

1.26 Código de Barras e RFID LACINHO

🌐 2. Economia Internacional

2.1 Por que o Comércio Internacional Existe?

Países trocam porque têm vantagens comparativas — cada um produz aquilo que custa menos em termos de oportunidade. Ganho mútuo.

TeoriaAutorIdeia central
Vantagem AbsolutaAdam SmithProduzir com menos recursos físicos
Vantagem ComparativaDavid RicardoProduzir com menor custo de oportunidade
Heckscher-OhlinH-OExportar bem que usa fator abundante do país
Diferença-chave: Vantagem absoluta = produz mais com menos recursos. Vantagem comparativa = custo de oportunidade menor. Países SE COMPARAM mesmo que um seja absolutamente melhor em tudo.

2.2 Balança de Pagamentos LACINHO

Superávit: mais entradas que saídas. Déficit: mais saídas que entradas.

2.4 Mercado Cambial LACINHO

Onde se compra e vende moedas estrangeiras. Agentes: bancos, corretoras, trade companies, Banco Central.

Spot: câmbio para entrega imediata (D+2 para dólar). Forward: câmbio para entrega futura, taxa combinada hoje.

Câmbio Forward = hedge cambial. Empresa que vai receber US$ 1M daqui a 3 meses fixa a taxa hoje, eliminando risco de desvalorização do BRL.

2.5 Mercado de Opções Internacionais LACINHO

2.6 Crise Financeira de 2008 LACINHO — 🔥 Prova

Causa raiz: empréstimos subprime (hipotecas para risco) → empacotados em MBS (Mortgage-Backed Securities) e CDO (Collateralized Debt Obligations) → vendidos como seguros via CDS (Credit Default Swap).

Estouro: bolha imobiliária EUA (2007) → inadimplência → perda de valor dos títulos → Lehman Brothers quebra (15/09/2008) → crise de liquidez global → contágio para emergentes → crise dívida soberana Europa (2010).

Ponto de prova: A crise expôs risco sistêmico, falha regulatória e alavancagem excessiva. Respostas: TARP (resgate), juros a zero, QE (quantitative easing), Basileia III, Dodd-Frank.

💰 3. Gestão Financeira

3.1 Juros Simples

O que é: juros calculados apenas sobre o capital inicial. Não rende sobre juros.

Fórmula J = C × i × t
M = C + J = C(1 + i × t)

Dedução: se empresto R$ 1.000 a 5% ao mês por 3 meses, cada mês gera R$ 50 de juros → 3 × 50 = R$ 150.

Aplicabilidade: empréstimos curtos, contas a prazo simples, análise preliminar rápida.

Por que existe: modelo mais simples — usado quando o tempo é curto e não há reinvestimento dos juros.

Exemplo prático: Financiar R$ 5.000 a 2% ao mês por 6 meses → J = 5000 × 0,02 × 6 = R$ 600. Montante = R$ 5.600.

3.2 Juros Compostos LACINHO

O que é: juros sobre juros — o capital "trabalha" e gera rendimento acumulativo. É a regra de ouro das finanças.

Fórmula M = C × (1 + i)t

Dedução: a cada período, o montante vira novo capital. M = C×(1+i)×(1+i)×… = C(1+i)^t.

Aplicabilidade: financiamentos imobiliários, investimentos longo prazo, cálculo de inflação, preço de ações.

Por que existe: reflete a realidade — juros geram mais juros. É o crescimento exponencial.

Exemplo prático: R$ 1.000 a 4% ao mês, 2 meses → M = 1000 × (1,04)² = 1000 × 1,0816 = R$ 1.081,60.

3.3 Valor Presente (VP) LACINHO

O que é: quanto um valor futuro "vale hoje". Princípio: dinheiro hoje rende, então vale mais.

Fórmula VP = VF / (1 + i)t

Dedução: inverte juros compostos. Se VF = VP×(1+i)^t, então VP = VF/(1+i)^t.

Aplicabilidade: avaliar investimentos, comparar alternativas, precificar ativos, decisão de aceitar/rejeitar projeto.

Exemplo prático: Receber R$ 1.157,63 daqui a 2 meses a 4% ao mês → VP = 1157,63 / (1,04)² = R$ 1.000. Ou seja, R$ 1.000 hoje = R$ 1.157,63 daqui a 2 meses a 4% a.m.

3.4 Valor Futuro (VF)

Fórmula VF = VP × (1 + i)t

O que é: quanto um valor hoje vale no futuro. É a inversa do VP.

Aplicabilidade: planejamento de metas ("quanto preciso guardar hoje para ter R$ X no futuro?").

3.5 TIR — Taxa Interna de Retorno LACINHO

O que é: taxa que torna o VPL = 0 (o investimento se paga sozinho).

Fórmula 0 = −C₀ + CF₁/(1+TIR)¹ + CF₂/(1+TIR)² + … + CFn/(1+TIR)n

Dedução: partimos do VPL, igualamos a zero e isolamos a taxa. Na prática, calcula-se por tentativa-e-erro ou HP-12C/Excel (função TAXA).

Aplicabilidade: decidir se projeto vale a pena: TIR > custo de capital → aceitar.

Regra de decisão: TIR > custo de capital → projeto rentável (gera valor). TIR < custo → destrói valor → rejeitar.

Exemplo prático: Investimento R$ 1.000; fluxos R$ 400, R$ 500, R$ 600 (3 anos). TIR ≈ 23,4% (calculado por tentativa). Se custo de capital = 10% → aceitar (23,4% > 10%).

3.6 VPL — Valor Presente Líquido LACINHO

Fórmula VPL = −C₀ + Σ CFt / (1 + k)t

Dedução: traz todo fluxo futuro a valor presente (desconto) e subtrai o investimento inicial.

Aplicabilidade: comparar projetos — maior VPL = maior valor criado para acionistas.

Exemplo prático: Projeto: C₀ = R$ 1.000; CF = 400, 500, 600 (3 anos); k = 10%.
VPL = −1000 + 400/1,1 + 500/1,21 + 600/1,331 = −1000 + 363,64 + 413,22 + 450,79 = R$ 227,65 → aceitar (VPL > 0).

Regra: VPL > 0 → aceitar. VPL < 0 → rejeitar. VPL = 0 → indiferente.

3.8 Custo de Capital (WACC) LACINHO

Fórmula WACC = wd × kd × (1 − t) + we × ke

wd = peso da dívida · kd = custo da dívida (juros) · t = taxa de impostos · we = peso do patrimônio · ke = custo do patrimônio (CAPM).

O que representa: retorno mínimo que a empresa precisa gerar para satisfazer investidores (dividendos + juros).

Aplicabilidade: taxa de desconto no VPL, barreira mínima para novos projetos. Se projeto não rende WACC → destrói valor.

3.9 CAPM — Capital Asset Pricing Model

Fórmula ke = Rf + β × (Rm − Rf)

Rf = taxa livre de risco (Tesouro Selic) · β = risco relativo ao mercado · Rm = retorno esperado do mercado.

O que é: calcula o retorno exigido pelo investidor conforme o risco do ativo.

β > 1: mais volátil que o mercado · β < 1: menos volátil · β = 1: mesmo risco do mercado.

3.10 Ponto de Equilíbrio LACINHO

Fórmula PE = CF / (P − CV)
PEtotal = (CF + Depreciação) / (P − CV)

CF = custos fixos (aluguel, salários) · P = preço de venda · CV = custo variável unitário (matéria-prima, comissão).

Dedução: no PE, Receita = Custos totais. R = P×Q; CT = CF + CV×Q → P×Q = CF + CV×Q → Q×(P−CV) = CF → Q = CF/(P−CV).

Exemplo prático: CF = R$ 10.000/mês, P = R$ 50, CV = R$ 30 → PE = 10.000/(50−30) = 10.000/20 = 500 unidades/mês.

Margem de contribuição: (P − CV) = quanto cada unidade contribui para cobrir custos fixos. Aqui: R$ 20/unidade.

3.12 Rentabilidade vs Retorno

Rentabilidade (ROE/ROA): quanto a empresa gera de lucro sobre o patrimônio/ativos. Mede eficiência.

Retorno (CAPM): quanto o investidor exige como compensação pelo risco assumido.

Regra: ROE > custo de capital → empresa cria valor. ROE < custo → destrói valor.
